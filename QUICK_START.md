## 🐛 Troubleshooting

### Backend won't start?
```bash
cd backend
npm install
npm start
```

### Frontend won't start?
```bash
cd frontend
npm install
npm start
```

### Chatbot not responding?
1. Check if backend is running (port 5000)
2. Check browser console for errors
3. Try refreshing the page

### Images not showing?
- Check internet connection (uses Unsplash)
- Fallback placeholders will load
